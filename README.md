# Portfólio de Design — ETE

Site de portfólio criado com HTML e CSS e preparado para publicação no GitHub Pages.

## Personalização antes de publicar
1. Substitui o texto genérico em `index.html` pela tua apresentação.
2. Atualiza o e-mail `teu.email@example.com`.
3. Substitui os cartões demonstrativos pelas imagens dos teus trabalhos autorizados.
4. Confirma que tens autorização para publicar cada material do projeto ETE.
5. Nunca publiques dados pessoais de terceiros, credenciais ou ficheiros confidenciais.

## Publicar com GitHub Pages
1. Cria um repositório público no GitHub, por exemplo `portfolio-ete`.
2. Carrega `index.html`, `style.css`, `README.md`, a pasta `images/` e a pasta `projects/`.
3. Abre **Settings → Pages**.
4. Em **Build and deployment**, escolhe **Deploy from a branch**.
5. Escolhe a branch `main` e a pasta `/(root)`, depois guarda.
6. Aguarda a publicação e usa o endereço apresentado na secção Pages.

O endereço de um site de projeto costuma seguir o formato `https://NOME-DE-UTILIZADOR.github.io/portfolio-ete/`.

## Estrutura
- `index.html` — conteúdo do site
- `style.css` — estilos visuais
- `images/` — imagens otimizadas dos projetos
- `projects/` — notas e estudos de caso
